이미 설치한 분은 앱을 열면 최신 화면으로 자동 업데이트됩니다. APK는 껍데기가 바뀌었을 때만 다시 받으면 됩니다.

A 안드로이드 설치 방법

  1. 내려받은 파일 열기화면 위쪽 알림을 누르거나, 내 파일 → 다운로드 → hanyang-pcw.apk
  2. “출처를 알 수 없는 앱” 허용설치 화면에서 안내가 뜨면 설정 → 허용을 눌러 주세요. (한 번만 하면 됩니다)
  3. 설치 → 열기홈 화면에 한양 pcw팀 아이콘이 생깁니다.
  4. 이름 · 생년월일 · 전화번호로 로그인관리자는 직종에서 관리자를 고르면 전체 현황 화면이 열립니다.

i 아이폰은 홈 화면에 추가

  1. 위의 웹앱 바로 열기 누르기Safari에서 앱이 열립니다. (크롬이 아닌 Safari에서 열어야 합니다)
  2. 아래쪽 공유 버튼 누르기네모 위로 화살표가 뜬 모양입니다.
  3. 홈 화면에 추가 선택 → 추가홈 화면에 한양 pcw팀 아이콘이 생기고, 앱처럼 전체 화면으로 열립니다.
