# 신규입사자 서류 제출 (onboarding)

한양이엔지(주) PCW 현장 신규입사자용 **모바일 제출 페이지**와 **관리자 페이지**입니다.

- 제출: `https://bakseoha27.github.io/Hanyang_pcw/onboarding/`
- 관리자: `https://bakseoha27.github.io/Hanyang_pcw/onboarding/admin.html`

## 어떤 정보를 다루나

주민등록번호 전체, 신분증·통장사본, 건강검진 결과(민감정보)를 받습니다. 그래서 이 앱은
`한양 pcw팀` 앱의 다른 테이블과 **보안 구조가 다릅니다.**

| 구분 | 권한 |
|---|---|
| `anon` (브라우저 공개 키) | `onboarding_submissions` **INSERT 만** · Storage `onboarding-docs` **업로드만** |
| 조회 / 내려받기 / 삭제 | `anon` 불가 (정책·권한 없음) |
| 관리자 | Edge Function `onboarding-admin` (서비스롤 키는 함수 안에서만) |

관리자 인증은 **지정 관리자(이름 + 전화번호, `onboarding_admins`)** + **관리자 암호**
(`app_secrets.admin_passcode`, SHA-256 대조) 두 가지를 모두 만족해야 합니다.
지정 관리자를 추가하려면 DB에서:

```sql
insert into public.onboarding_admins (name, phone) values ('이름', '010-0000-0000');
```

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` · `js/submit.v2.js` | 신규입사자 제출 폼 (모바일 우선) |
| `js/exam.js` · `vendor/pdfjs/` | 건강검진 PDF 자동 인식 (PDF.js 로컬 번들 + cmaps) |
| `js/guide.js` · `assets/guide/stepN.jpg` | 카톡에서 검진 PDF 찾는 법 (STEP 1~7) |
| `admin.html` · `js/admin.v2.js` | 관리자 조회 · 엑셀 취합 · ZIP · 입사취소 파기 · 파일 이름/검진일 수정 |
| `js/config.v2.js` | Supabase URL · anon 키 · 서류 종류 |
| `vendor/` | ExcelJS · JSZip · PDF.js (CDN 대신 저장소에 포함 → 오프라인·차단망에서도 동작) |

> 파일 이름 뒤의 `.v2` 는 서비스워커(`/sw.js`) 캐시를 피하려고 붙였습니다. 안에 있는 파일을 고칠 때는
> 이름을 올리고(`v3`) HTML 의 `<link>`·`<script>` 도 같이 바꿔 주세요. HTML 은 네트워크 우선이라 그대로 반영됩니다.

## 파일 이름 규칙 (자동 변환)

| 서류 | 저장 이름 |
|---|---|
| 신분증 | `신분증(성명).확장자` |
| 기초안전보건교육 이수증 | `기초이수증(성명).확장자` |
| 통장사본 | `통장사본(성명).확장자` |
| 증명사진 | `성명_생년월일6자리.jpg` (Canvas로 JPG 변환) |
| 건강검진 (여러 개) | `YYMMDD_성명 일반.pdf` / `배치전` / `특수` — 파일마다 하나씩 |
| 소견서 | `성명 소견서.pdf` |
| 약봉투 | `성명 약봉투.확장자` (사진 또는 PDF, 선택) |
| 경력증명서 | `성명 경력증명서(용접공).pdf` (용접공 체크 시) / `성명 경력증명서.pdf` |

건강검진은 PDF 첫 1~2쪽 글자를 PDF.js 로 읽어 **검진일자**(`검진일자`·`2026년 10월 16일`·`2026.10.16`·`2026-10-16` 등)와
**검진종류**(`배치전`·`특수`·`일반` 키워드)를 찾아 이름을 만듭니다. 스캔본처럼 글자가 없으면 화면에서 날짜·종류를 직접 고릅니다.

### 자동 판독 규칙 (2026-11-27 추가)

- **D2 판정**: 검진 PDF 글자에 `D2`(예: `판정 D2`, `건강구분 : D2`, `D2 유소견`)가 있으면 빨간 안내창을 띄우고
  **소견서를 필수**로 바꾸며, **약봉투 사진 업로드 칸**(`성명 약봉투.ext`, 선택)을 붉게 강조합니다.
  D2인데 소견서가 없으면 제출을 막습니다. D2 여부는 `files_json` 의 해당 파일 `d2: true` 로 저장됩니다.
- **검진일 1년 유효**: 검진일이 **오늘 기준 1년 전 같은 날짜**보다 이전이면
  `❌ 검진일로부터 1년이 지난 서류는 사용할 수 없습니다...` 를 띄우고 제출을 막습니다(수동 입력 날짜도 동일).

Storage 객체 키는 ASCII만 허용되므로 실제 경로는 `{제출id}/{서류종류}.{확장자}`이고,
위의 한글 이름은 DB(`files_json`)에 저장해 **다운로드할 때 그 이름으로** 내려받습니다.

## 엑셀 취합

관리자 페이지의 **[📊 엑셀 취합 다운로드]** 는 서하 님의 실제 양식(`확정 (2)` 시트)의
열 순서·너비·머리글 색을 그대로 따릅니다.

`No. · 성명 · 주민번호 · 입사일자 · 주소 · 핸드폰기종 · 휴대폰 · 월급/일당 · 은행명 ·
계좌번호 · 직종 · 숙소 · 총경력 · 반도체경력 · 이메일 · 혈액형 · 조끼 사이즈 ·
안전화 사이즈 · 보안경(일반/안경) · 보유 자격 현황`

그 뒤에 **서류 제출 현황**(신분증·기초이수증·통장사본·증명사진·건강검진·소견서·경력증명서 O/X,
검진일/종류, 제출일, 상태, 동의 일시 3종)을 덧붙입니다.
`입사일자`는 제출 폼에서 받지 않으므로 빈칸으로 나옵니다.
`숙소` 열은 양식 순서를 지키려고 남겨 두고 **항상 빈칸**입니다(숙소 입력란은 2026-11-27 제거).
`직종` 열은 **용접공 체크 시 `용접공`, 아니면 빈칸**입니다. 건강검진을 여러 개 올리면 `검진일 / 종류` 칸에
`2026-10-16 배치전 / 2026-10-16 일반` 처럼 모두 적힙니다.

## 제출 항목 (2026-11-27 기준)

- 필수: 성명 · 주민번호 · 주소 · 휴대폰 기종/번호 · 본인 명의 · 은행/계좌 · 단가 · 총 경력 · **반도체 경력** ·
  **이메일** · 혈액형 · 조끼/안전화 · 보안경 · 신분증 · 기초이수증 · 통장사본 · 증명사진 · **건강검진 PDF(1개 이상, 각 파일에 검진일·종류)** · 경력증명서 · 동의 3종
- 선택: 용접공 여부 · 보유 자격 · 소견서 · 약봉투
- D2 판정 시 소견서는 필수로 바뀝니다.
- 없어진 항목: `숙소 사용`(폼·DB 저장값), `직종` 선택(→ `용접공` 체크만)
- DB `housing` 컬럼은 그대로 두고 `null` 저장, `job_role` 은 `'용접공'` 또는 `''`
