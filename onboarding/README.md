# 신규입사자 서류 제출 (onboarding)

한양이엔지(주) PCW 현장 신규입사자용 **모바일 제출 페이지**와 **관리자 페이지**입니다.

- 제출: `https://bakseoha27.github.io/Hanyang_pcw/onboarding/`
- 관리자: `https://bakseoha27.github.io/Hanyang_pcw/onboarding/admin.html`

## 어떤 정보를 다루나

주민등록번호 전체, 신분증·통장사본, 건강검진 결과(민감정보)를 받습니다. 그래서 이 앱은
`한양 pcw팀` 앱의 다른 테이블과 **보안 구조가 다릅니다.**

| 구분 | 권한 |
|---|---|
| `anon` (브라우저 공개 키) | `onboarding_submissions` **INSERT 만** · Storage `onboarding-docs` **업로드만** |
| 조회 / 내려받기 / 삭제 | `anon` 불가 (정책·권한 없음) |
| 관리자 | Edge Function `onboarding-admin` (서비스롤 키는 함수 안에서만) |

관리자 인증은 **지정 관리자(이름 + 전화번호, `onboarding_admins`)** + **관리자 암호**
(`app_secrets.admin_passcode`, SHA-256 대조) 두 가지를 모두 만족해야 합니다.
지정 관리자를 추가하려면 DB에서:

```sql
insert into public.onboarding_admins (name, phone) values ('이름', '010-0000-0000');
```

## 파일 이름 규칙 (자동 변환)

| 서류 | 저장 이름 |
|---|---|
| 신분증 | `신분증(성명).확장자` |
| 기초안전보건교육 이수증 | `기초이수증(성명).확장자` |
| 통장사본 | `통장사본(성명).확장자` |
| 증명사진 | `성명_생년월일6자리.jpg` (Canvas로 JPG 변환) |
| 건강검진 (여러 개) | `YYMMDD_성명 일반.pdf` / `배치전` / `특수` — 파일마다 하나씩 |
| 소견서 | `성명 소견서.pdf` |
| 약봉투 | `성명 약봉투.확장자` (사진 또는 PDF, 선택) |
| 경력증명서 | `성명 경력증명서(용접공).pdf` (용접공 체크 시) / `성명 경력증명서.pdf` |

건강검진은 PDF 첫 1~2쪽 글자를 PDF.js 로 읽어 **검진일자**(`검진일자`·`2026년 10월 16일`·`2026.10.16`·`2026-10-16` 등)와
**검진종류**(`배치전`·`특수`·`일반` 키워드)를 찾아 이름을 만듭니다. 스캔본처럼 글자가 없으면 화면에서 날짜·종류를 직접 고릅니다.

### 자동 판독 규칙 (2026-11-27 추가)

- **D2 판정**: `소견서`·`약봉투` 칸은 **평소 숨김**이고, 검진 영역 아래 **`D2 판정이신가요?`** 체크로 엽니다.
  검진 PDF 글자에 `D2`(예: `판정 D2`, `건강구분 : D2`, `D2 유소견`)가 있으면 **체크가 자동으로 켜지며** 칸이 펼쳐지고,
  빨간 안내창으로 **소견서(필수)·약봉투(선택)** 를 안내합니다. 체크를 끄면 다시 접히지만,
  PDF에서 D2가 감지된 경우엔 **소견서 필수는 그대로 유지**됩니다(안내창의 버튼으로 칸을 다시 열 수 있음).
  D2인데 소견서가 없으면 제출을 막습니다. D2 여부는 `files_json` 의 해당 파일 `d2: true` 로 저장됩니다.
- **검진일 1년 유효**: 검진일이 **오늘 기준 1년 전 같은 날짜**보다 이전이면
  `❌ 검진일로부터 1년이 지난 서류는 사용할 수 없습니다...` 를 띄우고 제출을 막습니다(수동 입력 날짜도 동일).

Storage 객체 키는 ASCII만 허용되므로 실제 경로는 `{제출id}/{서류종류}.{확장자}`이고,
위의 한글 이름은 DB(`files_json`)에 저장해 **다운로드할 때 그 이름으로** 내려받습니다.

## 관리자 — 진행중 / 취합완료 탭

- 상단 **`[진행중 (N)]` · `[취합완료 (M)]`** 탭. 기본은 **진행중**(`archived_at is null`)만 보입니다.
- 인원을 체크하고 **[✅ 취합완료로 이동]** 을 누르면 `archived_at = now()` 로 [취합완료] 탭에 옮겨집니다.
- [취합완료] 탭에서는 취합일시가 표시되고, 엑셀·ZIP·상세 조회·삭제와 **[↩ 진행중으로 복구]** 가 가능합니다.
- 이동·복구는 Edge Function `onboarding-admin` 의 `archive` / `unarchive` 액션이 처리합니다.

## 관리자 — 목록 표 · 기본 정보 수정 · 신규자 직접 추가

- 목록은 표(가로 스크롤)입니다: **이름(`[외주]` 배지) · 생년월일 · 연락처 · 입사일자 · 퇴사일자 · 단가 · 성별**.
  생년월일은 `birth6`(주민번호 앞 6자리)와 성별 코드로 `YYYY-MM-DD` 로 계산해 보여 줍니다.
- 상세 시트 위 **기본 정보** 칸에서 **외주 여부 · 입사일자 · 퇴사일자 · 단가 · 성별**을 고쳐
  **[기본 정보 저장]** 하면 `onboarding-admin` 의 `update_meta` 액션이 저장합니다.
- **[➕ 신규자 직접 추가]** 모달로 서류 없이 기본 정보만 등록할 수 있습니다(`create_manual`):
  성명 · 주민등록번호 · 생년월일 · 성별 · 연락처 · 입사일자 · 퇴사일자 · 단가 · 소개자 · 외주 여부.
  주민등록번호나 생년월일을 넣고 성별을 비워 두면 뒷자리 첫 글자(1·3·5·7·9 남 / 2·4·6·8·0 여)로 자동 계산합니다.
- 신규자가 제출할 때도 주민등록번호 뒷자리로 `gender` 를 자동 계산해 저장합니다(DB `gender`: `'여'`/`'남'`).
- DB 추가 컬럼: `is_outsource`(외주, 기본 false) · `hire_date` · `resign_date` · `gender` (모두 text/boolean).

## 엑셀 취합

관리자 페이지의 **[📊 엑셀 취합 다운로드]** 는 서하 님의 실제 양식(`확정 (2)` 시트)의
열 순서·너비·머리글 색을 그대로 따릅니다.

`No. · 성명 · 외주 · 주민번호 · 성별 · 입사일자 · 퇴사일자 · 주소 · 핸드폰기종 · 휴대폰 · 월급/일당 · 은행명 ·
계좌번호 · 입금자명 · 직종 · 숙소 · 총경력 · 반도체경력 · 이메일 · 혈액형 · 조끼 사이즈 ·
안전화 사이즈 · 보안경(일반/안경) · 보유 자격 현황 · 소개자`

그 뒤에 **서류 제출 현황**(신분증·기초이수증·통장사본·증명사진·건강검진·소견서·경력증명서 O/X,
검진일/종류, 제출일, 상태, 동의 일시 3종)을 덧붙입니다.
`입사일자`는 관리자가 넣은 `hire_date` 값을, `퇴사일자`는 `resign_date`, `외주`는 `is_outsource`(O/빈칸), `성별`은 `gender` 를 씁니다.
`숙소` 열은 양식 순서를 지키려고 남겨 두고 **항상 빈칸**입니다(숙소 입력란은 2026-11-27 제거).
`직종` 열은 **용접공 체크 시 `용접공`, 아니면 빈칸**입니다.
`입금자명` 열은 `입금자명(예금주)` 입력값이며, **`본인 명의` 가 체크되어 있으면 `성명` 과 같습니다**(DB `account_holder`). 건강검진을 여러 개 올리면 `검진일 / 종류` 칸에
`2026-10-16 배치전 / 2026-10-16 일반` 처럼 모두 적힙니다.

## 제출 항목 (2026-11-27 기준)

- 필수: 성명 · 주민번호 · 주소 · 휴대폰 기종/번호 · 본인 명의 · 은행/계좌 · **입금자명(예금주)** · 단가 · 총 경력 · **반도체 경력** ·
  **이메일** · 혈액형 · 조끼/안전화 · 보안경 · 신분증 · 기초이수증 · 통장사본 · 증명사진 · 경력증명서 · 동의 3종
- **건강검진은 선택**(2026-11-27부터). 올리지 않아도 제출되며, 올린 파일은 검진일·종류와 1년 유효기간을 그대로 검사합니다.
- 선택: 용접공 여부 · 보유 자격 · **건강검진** · 소견서 · 약봉투 · **소개자/추천인**
- 단가 칸은 자유 입력(`미기재` 도 허용). 서류는 **📷 사진 올리기**(신분증·기초이수증·통장사본·증명사진)와
  **📄 서류 올리기**(건강검진·경력증명서·D2) 두 구역으로 나뉘고, 카드에는 변환 파일명이 아니라 **짧은 이름과 원본 파일명**만 보입니다
  (변환된 저장 이름은 DB `files_json`·관리자 상세·ZIP 에만 쓰입니다).
- 소견서·약봉투 칸은 `D2 판정이신가요?` 체크(또는 검진 PDF의 D2 자동 감지)일 때만 나타나고, 그때 소견서는 필수입니다.
- `입금자명(예금주)` 는 `본인 명의` 체크 시 `성명` 과 실시간 동기화되고, 체크를 풀면 직접 입력할 수 있습니다.
- 없어진 항목: `숙소 사용`(폼·DB 저장값), `직종` 선택(→ `용접공` 체크만)
- DB `housing` 컬럼은 그대로 두고 `null` 저장, `job_role` 은 `'용접공'` 또는 `''`

## 배포

```bash

cp -r projects/onboarding-portal/web/* work/gh-hanyang-pcw/onboarding/
cd work/gh-hanyang-pcw && git add onboarding && git commit -m "..." && git push

# 엣지 함수를 고쳤을 때
python3 projects/onboarding-portal/deploy_fn.py onboarding-admin \
  projects/onboarding-portal/edge-functions/onboarding-admin/index.ts
```
